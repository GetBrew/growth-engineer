Datacircle is a sheet of the GTM APIs it finds, with one row for each plan
of each call: what it costs per 1,000, what it charges when it finds nothing,
its rate limits, its speed and the fields it returns.

Its API and its MCP server answer from the sheet and need no key. Anyone can also
download the whole sheet as CSV, JSON or a zip, with no sign-up.
