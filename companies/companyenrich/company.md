CompanyEnrich provides B2B company and people data for platforms, AI agents
and go-to-market workflows. Its REST API enriches company profiles from
domains, searches companies with structured filters or natural-language
queries, finds lookalike companies, searches professional profiles and
looks up people from email addresses.

The API uses a bearer API key and charges credits by endpoint and results
returned. An official [remote MCP server](https://docs.companyenrich.com/docs/mcp-server)
also connects compatible AI clients using a CompanyEnrich API key.
