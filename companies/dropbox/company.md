Dropbox stores and syncs files and folders and shares them by link, with named people, or through file requests that collect uploads from others. Its HTTP API takes OAuth 2 access tokens; its remote MCP server, in beta, gives agents the same kinds of actions: search, shared links, file requests and file management.
