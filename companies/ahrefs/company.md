Ahrefs indexes the web for search rankings, backlinks and keyword data.
Keywords Explorer returns search volume and difficulty for a list of
keywords; Site Explorer returns the keywords a domain or URL already ranks
for. A separate MCP server takes its own MCP-specific key, not the API key
above, so it isn't listed as a way in here.
