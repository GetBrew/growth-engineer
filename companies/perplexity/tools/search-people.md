name: Search for people
summary: Returns web results about professionals who match a name, role, company or location, with titles, URLs and snippets naming their jobs and employers.
capability: build-audience
docs: https://docs.perplexity.ai/docs/search/filters/people-search
api: POST /search
updated: 2026-09-27
---

Set `search_type` to `people` on a Search API request, with a query such as
`Stripe VP of Engineering`; `max_results` and the other Search API parameters
still apply. Use People Search only for legitimate professional research, and
follow the privacy and data protection laws that apply to you.
