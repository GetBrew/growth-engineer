Clerk is user management for developers: sign-up and sign-in with prebuilt UI
components, multi-tenant organizations, enterprise SSO, subscription billing
and machine-to-machine auth. Its Backend API and CLI read and manage an
application's users, invitations and waitlist, so new sign-ups can start a
growth workflow.
